## 使用

运行 `npm run dev` 后打开 `http://localhost:4188`。也可依次运行 `python3 source/build_browser.py` 和 `python3 source/serve.py`。

- 点「步入庭院」开始，并启用声音。
- 俯览时拖动环顾，滚轮或双指缩放。
- 点「走入寺院」，WASD / 方向键移动，拖动画面转头。手机显示方向键。
- 点击桥栏边的扫帚拿起，按住拖过地面的落叶；步行模式也可用空格扫前方。点「放回扫帚」或按 Esc，扫帚自动回到原位。
- 点击钟或按住钟旁绳子上下拖动，会摇响寺钟；钟与绳子随动作摆动，连击有短暂间隔。静音设置仍然有效。
- 点击主殿进入香炉近景，点击香头点燃。香在前台停留约三分钟燃尽，三秒内自动换上未点燃的新香，可再次点燃。离开近景仍会继续燃烧；页面隐藏时暂停。点「回到庭院」或按 Esc 退出。
- Esc 返回俯览；右上角可静音、查看操作帮助。

## 画面与行为

建筑已按精心修缮的日式庭园寺院丰富：双层釉面瓦屋顶与唐破风式前廊、鎏金檐线与菊纹、浮雕梁枋、细密格扇、柱脚铜箍、深色漆木桥栏、洁净花岗岩台基。入口有成对石雕守兽，庭园有五层石塔、六株修剪松、竹丛、山茶灌木和枯山水砂纹。自然池岸继续使用 2K 树皮与苔石，建筑改用带清漆反射的实拍细木纹和原创整修石材。水面采用独立反射与折射渲染，并分别处理天空倒影与水下光线吸收；桌面反射纹理为 1536 像素。池底有石子与低强度动态焦散。16 条锦鲤使用 Blender 原生模型，四种原创花色、鱼鳞法线、半透明鳍条、竖直尾鳍、眼睛、鳃盖、嘴唇与口须；身体连续弯曲，胸鳍轻摆，游动路线缓慢变化。16 条鱼按花色实例化共享绘制，保留完整网格与各自的运动相位。庭院树冠在桌面近景使用约十八万片独立叶片；落叶上限 3900 片，按时间缓慢累积，扫帚清扫半径为 2.4 米，快速拖动会连续覆盖整段轨迹；落叶被扫开后约 1 秒淡出，几次宽幅扫动即可清理一片区域。钟声采用原创泛音与混响合成，约 29–43 秒间隔。

主殿佛像使用 Daniel Pett 的唐代坐佛 CC0 摄影测量网格（Smithsonian F1917.243），在 Blender 中重新定位、鎏金，并原创修复双手与莲座。这是数字艺术改编，不声称是历史原貌复原。真实面容、耳廓、衣褶和盘坐轮廓来自扫描；网页提供近远两级模型，原始文件保留可编辑的修复部件。执行 `source/restore_buddha.py` 可复建新版，旧版生成脚本作为历史来源保留。

外围山体采用真正的起伏网格，地形保留池塘开口并接入庭院地面。620 棵林木分为近处独立叶片和远处原创枝叶贴片两级，按空间分批实例化；前景秋树的叶片收拢在枝梢附近。

光照使用实拍秋林 HDR 环境反射，配合方向光、环境遮蔽和桌面 4096 像素阴影；深色木构采用染色细木纹与清漆反射。

这是浏览器中的高细节风格化实时场景。它并不等同于商业 3A 游戏的摄影测量资产、完整角色雕刻、光线追踪或大规模美术制作。运行效果取决于设备 GPU；首屏需要加载模型。锦鲤与环境来自 Blender，网页中的鱼体形变和扫帚交互由 Three.js 驱动。模型可继续替换为更高规格的手工资产。

## 不可见水面的开销与分辨率恢复

`dist/water-surface.js` 使用水面真实世界包围盒判断主相机可见性，保留 1 cm 余量。主殿朝内时，旧包围球会误报相交，尽管所有水面三角形都在镜头后方；现在这类视角不触发倒影和折射。池边、俯览及部分水面仍可见时，立即恢复原有每帧、原分辨率的两次水面计算，不改变模型、鱼群、纹理或倒影内容。

一次同主殿视角、1.1 渲染比例的本机记录中，平均帧耗时从 48.6 ms 降至 26.1 ms；每 180 帧的水面两项捕获计数从各 180 次变成各 0 次，避免了每帧约 355 万个水面捕获三角形。数值随设备和系统负载变化；原始记录保存在本地 `evidence/water-visibility-*.json`。返回室外已观察到两项捕获恢复至各 180 次。

`dist/render-quality.js` 将分辨率在设备允许的 1.1、1.35、1.6 档位间调整。降档阈值与升档阈值分开，升档要求连续两个低耗时采样窗口，并保留 12 秒冷却；预算足够时可以恢复细节，不再永久停留在低分辨率。EffectComposer 的实际目标尺寸也在初始化和缩放时与渲染比例同步。

### 庄严内殿（2026-10-07）
保留已认可的唐代佛像和铸铜香炉，新增原创矿物彩壁画、嵌框护墙、真正向上凹入的八角藻井、莲花井心、斗栱、雕花供桌、七只供水杯、两组果盘和莲花瓶、四组长明红烛。入殿使用较宽视角，可以抬头和平移观察；相机仍受地面、墙面和顶面约束。没有新增漂浮道具文字。
