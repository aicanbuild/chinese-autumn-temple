# Share world matrices across a rendered frame

All application transform animation finishes before `renderSceneFrame(scene, render)` updates the hierarchy once. Main color, water reflection/refraction and AO then use these same matrices. Each camera still updates normally. The original `matrixWorldAutoUpdate` setting is restored even if rendering throws. Manually maintained scenes remain manual. This helper is not suitable for render callbacks that change Object3D transforms; the temple callbacks change visibility, draw ranges, materials and uniforms, not transforms.

The six-view real-WebGL comparison in `scene-frame-fixture.html` loads the actual temple, bridge, basin, stones, koi and lamps. Fish are posed at a different time for each view. Before/after color and shadow bytes are identical at every view, with nonempty rendered images. Five views reduce complete scene matrix traversals from three to one; the side view that never draws water remains one. Triangle and draw counts are unchanged. See `evidence/scene-frame-comparison.json`. This fixture is a subset of the full scene and uses a 2048 shadow map; it is not a whole-scene performance benchmark.

The optional GPU timer is activated only with `?gpuProfile=1`; the existing `?profile=1` diagnostics do not activate it. Queries are asynchronous and bounded, use one inclusive scope per sampled frame, and discard disjoint/context-loss results. Nested scopes are intentionally not additive. Initial multi-query-per-frame sampling disturbed rendering and was rejected. Single-scope results still include GPU pipeline/query-boundary effects and must not be summed or treated as isolated hardware costs. The saved baseline is diagnostic evidence, not an FPS improvement claim. No geometry, texture resolution or capture frequency changed.

199 automated tests pass, including animated parent/child transforms across successive frames, nested/manual ownership, exception restoration, unavailable GPU results, context loss and unsupported extensions. Overall commercial AAA quality and performance remain incomplete.
