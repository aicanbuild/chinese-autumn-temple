# 参考驱动的藻井彩绘与雕花加密

依据用户提供的三张藻井照片中的装饰层级，保留原有八角藻井结构与细梁尺寸，重制原先稀疏的贴面卷草层。不是对照片纹理的裁剪或对具体寺院的复刻。

- 32 面阶梯底板：64 组带双重金框、十二瓣彩画莲花和八瓣实体金花心的格子；两道连续朱红回纹、珠边和卷草。
- 16 块侧面方格：石青底色、朱红套框、金色珠边及四角团花，保留原有立体莲花。
- 中央：32 道成对金色螺旋卷草、两道细环及贴合既有大莲花曲面的细叶脉。
- 四角：三角金线框与 32 道卷草环绕既有角花。

`paint_caisson_panels.py` 以可复现的原始矢量路径绘制 3072×1024 彩画和 1024×1024 方格贴图；微弱颜料颗粒避免粗大木纹。`enrich_caisson.py` 替换被明确标记的旧 caisson_vines 对象，备份并同步两份 Blender 工程；保存后重开核对非目标网格、UV 与世界变换。分别保持 3589 / 10064 个对象不变。新增装饰 83 个原生部件，网页合批为 3 个材质批次、273648 三角形、3395284 字节。

彩绘使用非金属材质；几何金饰共享既有室内金材质与反射。模块验证三种完整批次，避免漏载时悄悄显示残缺场景。装饰单元数量与材质数据更新于 sanctuary.json。

`verify_caisson_enrichment.py` 独立读取保存后的实际支撑网格，对 138440 个新增顶点核对最近距离：彩画最大约 0.651mm，浮雕最大约 6.015mm。24 项构建、材质集成、遮挡、反射、灯光与 LOD 测试通过。原生证据在本地 evidence/caisson-enrichment-native.json 与 caisson-enrichment-support.json。临时检查页由 build_enriched_caisson_audit.py 生成。
