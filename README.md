# Chinese Autumn Temple

**English** · [简体中文](README.zh-CN.md)

A quiet autumn temple garden you can explore in your browser. Walk around, watch the water, and take part in small, unhurried rituals. The scene and models are made with Blender; Three.js brings the water, lighting, and interactions to life.

[Live demo](https://quiet-autumn-temple.lovzoe.chatgpt.site/) · [Asset credits](ASSET_CREDITS.md) · [Blender source files](https://github.com/aicanbuild/chinese-autumn-temple/releases/tag/v1.0.0)

![The autumn temple courtyard](docs/courtyard.png)

## Explore and interact

- Look around the main hall, wooden bridge, pond, and autumn woodland. Get closer to the lotus flowers, koi, and flowing stream.
- Click a fish or the pond surface: ripples spread, and nearby fish swim away.
- Pick up the broom beside the bridge, sweep fallen leaves, and put it back.
- Pick up the wooden ladle at the entrance, stir and scoop water, pour it from the side, and return it.
- Ring the bell and let its sound fade.
- Enter the dark hall and light four candles, one by one. The candles reset each time you enter.
- Light incense and watch the smoke rise, or pick up the wooden fish percussion instrument and strike it at your own pace.

The scene has a sound toggle. A return control appears when you hold a prop or enter the hall. There are no floating instruction labels over the objects.

## Run locally

You need Python 3. The web dependencies and exported models are included in the repository. No API key or Blender installation is needed to run the website.

```sh
git clone https://github.com/aicanbuild/chinese-autumn-temple.git
cd chinese-autumn-temple
python3 source/build_browser.py
python3 -m http.server 4188 --bind 127.0.0.1 --directory dist
```

Open <http://localhost:4188/>. Use an HTTP server rather than opening the HTML file directly.

If you also have Node.js installed, these commands are available:

```sh
npm run build
npm run dev
npm test
```

Use the arrow keys to pan, drag to look around, and scroll to zoom. Camera limits help keep the view above ground. The first load downloads substantial model and texture data; a desktop browser with WebGL 2 support is recommended.

## Edit and deploy

The editable web modules are in `dist/*.js`. Exported GLB models, textures, and layout data are in `dist/assets/`. After making changes, run `python3 source/build_browser.py` and refresh the browser. `dist/runtime/` is generated by this script and should not be edited directly.

After building, upload the entire `dist/` directory to a static website host. Include the models and locally vendored Three.js dependencies. The website has no backend or account system.

`source/` contains Blender modeling, export, and material-generation scripts, along with Node.js checks and focused WebGL comparison pages. Some modeling scripts require the native `.blend` files provided in the release; material-generation scripts may also require NumPy and Pillow. See the [Blender notes](docs/blender.md) and [development notes](docs/development-notes.md), currently in Chinese, for the individual workflows.

## Blender project

Download `chinese-autumn-temple-blender-source.zip` from the [v1.0.0 release](https://github.com/aicanbuild/chinese-autumn-temple/releases/tag/v1.0.0) and extract it into the repository root. The archive contains 32 current Blender projects. Open `source/听秋寺院.blend` for the assembled temple; separate projects cover the hall, stream, ladle basin, wooden fish, plants, and other scene components.

These files were created with Blender 4.x. Blender 4.5 or a newer compatible version is recommended. Modeling scripts have individual prerequisites and are not a single rebuild pipeline that can be run in any order.

## Rendering and performance

This is a detailed, stylized real-time web scene. Water uses reflection, refraction, and procedural motion approximations; smoke and sound also include procedural effects. It is not a full fluid simulation or a commercial AAA game engine. GPU capability and window resolution affect loading time and frame rate. Contributions to texture reuse, progressive loading, and rendering performance are welcome.

The current check suite has **307 passing checks** and **two explicitly skipped legacy bake-provenance checks**. The skipped checks refer to older Buddha geometry and sanctuary layout metadata; they still need a fresh bake or independent audit. Their original assertions remain intact. See [known limitations](docs/known-limitations.md).
